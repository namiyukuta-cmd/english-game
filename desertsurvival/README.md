# Desert Survival

砂漠を自由に歩き、物を集め、クラフトし、都市・水場・交易路を探索するサバイバルゲーム。

## 基本方針

- HTML は画面レイアウトを担当する。
- ゲーム内容・計算・データ・描画は JS に分離する。
- フィールドは基本的に 1 枚の `desertsurvival_field.html` で歩き回る。
- 大量の地点ごとに HTML を増やさず、マークポイントのデータを追加して世界を広げる。
- 画面右上に円形ミニマップを表示し、押すと全体マップを開く。×で閉じてフィールドへ戻る。
- 下部に「調べる」「ITEM」「RUN」「移動スティック」を配置する。

## HTML

### desertsurvival_index.html

開始画面。

- 新しく始める
- 続きから
  - `namiyukuta-cmd/private-game-data` の `desertsurvival-saves/` を読む。
- 設定
  - GitHub トークンを設定する。
  - トークンはブラウザの localStorage のみへ保存する。

### desertsurvival_field.html

冒険するフィールド画面。

- 「新しく始める」「続きから」のどちらでも最初にここへ入る。
- プレイヤーパラメータ
- 円形ミニマップ
- 全体マップオーバーレイ
- 調べる
- ITEM
- RUN
- 移動スティック

### desertsurvival_menu.html

メニュー画面。タブ形式で増やす。

現在のタブ：

- 所持品（装備を含む。所持品 ⇄ 装備の移動が可能）
- 作れる物

将来、必要になったらスキル等のタブを追加する。

## JS

### player.js

主人公の状態と主人公自身の基本計算。

- 体力 0-100
- 水 0-100
- 食 0-100
- 睡眠 0-100
- 体温 ℃
- 所持金
- 状態異常

外気温・天候などは他 JS から受け取り、主人公への影響をここで計算する。

### items.js

主人公の所持品とアイテム基本データ。

### equipment.js

身につけている物。所持品との行き来を担当する。

### recipes.js

クラフトレシピと作成可能判定。

### time.js

ゲーム内時間を進める。初期設定は現実 1 秒 = ゲーム内 1 分。

### clock.js

`time.js` の時刻を読み、24時間で一周する円形時計を描画する。

### temperature.js

外気温。日中は暑く、夜間は寒い砂漠の一日を表現する。

### weather.js

通常は晴れ。ゲーム内1時間ごとに低確率で砂嵐を抽選する。

### world.js

実際に歩き回る世界の土台。

- ワールド座標
- 現在位置
- 地域
- 移動距離
- 移動距離から経過時間への換算

### map.js

世界を地図として表示する。

- 円形ミニマップ
- 全体マップ
- 現在地
- 発見済みマークポイント

### markpoints.js

世界各地の地点を一括管理する。

番号帯：

- 001-099 水場・井戸・オアシス
- 100-199 町・集落
- 200-299 宿営地・隊商拠点
- 300-399 鉱山・採取地点
- 400-499 遺跡・特殊地点

番号は分類用であり、各帯を100個作る必要はない。

### markpoint-common.js

地点種別ごとの共通処理。

例：

- 水場：飲む / 水を汲む / 調べる
- 町：町に入る / 調べる
- 宿営地：休む / 調べる
- 採取地点：採取する / 調べる

### save.js

Desert Survival のゲーム状態と GitHub セーブを管理する。

保存先：

- repository: `namiyukuta-cmd/private-game-data`
- directory: `desertsurvival-saves/`

## 予定している専用インベントリ画面

まだ HTML は作っていない。

### 拾うインベントリ

- 拾う物
- 所持品
- 装備

の3つを同時表示し、持てる条件の範囲で相互に移動できる。

### 売買インベントリ

主人公側と相手側を表示する。

- 相手側へ移した段階では売買未確定。
- 元へ戻せる。
- 最後に「決定」を押した時だけ売買を確定する。

## マップ参考方針

イブン・バットゥータの14世紀西スーダン旅行路を軸に、サハラ交易路、都市、井戸、水場、オアシス、宿営地点、岩塩産地などを追加してゲーム用マップを作る。

単一年代ではない古い交易路資料を使う場合は、14世紀の地点と区別して参考情報として扱う。
